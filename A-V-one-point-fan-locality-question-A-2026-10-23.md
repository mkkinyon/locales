# One-point fan locality for Question A

Let X be Hausdorff T1 with point t, and let X minus t be the union of pairwise disjoint clopen spaces Y_i. Suppose every bar restricted to Y_i has finite rank. Define j_fin as the join of nuclei of all finite-rank bars.

For any bar w set r=j_fin(w). Finite-block truncations yield (e box e)<=r, where e=X minus t. For each clopen c=Y_i and its complement d, the two strip bars p=(c box 1) join (1 box d), q=(d box 1) join (1 box c) have rank at most 2. They exclude the rectangles d box c and c box d respectively. Because p implies r=r and q implies r=r, both excluded rectangles lie below r. Adding c box c below e box e gives c box 1 and 1 box c below r. Join across i to obtain (e box 1) join (1 box e) below r. The only possible closed residual lies on the singleton square (t,t). Since w contains the diagonal point (t,t) and r is above w, no residual remains. Thus r=1, and the finite-rank-generated fitted sublocale equals V.

This applies to a one-point fan over copies of the iterated K-fan spaces with unbounded finite ranks. A new point with neighborhoods containing tails of suitable old opens gives a strip bar with well-founded rank omega, while equality V_fin=V persists. This rules out one-point accumulation as an easy counterexample to Question A.

# Rank substitution: functorial no-go and retract rigidity

Let L,M be frames, h:L->M a frame homomorphism, B subset L x L. Map labels coordinatewise under h. Disjointness leaves stay disjoint because h preserves finite meets and zero, B leaves map into h[B], exact horizontal/vertical covers remain exact because h preserves all joins, root stays (1,1). Therefore any well-founded B-separation tree in L maps to an h[B]-tree in M with same shape and no greater rank. For finite minimal depths, rank_M(h[B]) <= rank_L(B). This applies to transfinite tree ranks too, using the same original tree.

If h has a frame left inverse r:M->L satisfying r h=id_L, then applying the same result to r and the family h[B] gives rank_L(B) <= rank_M(h[B]), hence equality, for any rank notion defined as the minimum of ranks of witnesses.

This is an obstruction to rank amplification by frame-homomorphic reinterpretation, and particularly by split extensions, products, or retract constructions when the bar is only the coordinatewise image. A rank amplification must introduce new rectangles in a non-functorial fashion or new synchronization requirements that no frame retraction removes.

The result DOES NOT rule out all forms of substitution: one can alter the bar, and frame maps need not admit retractions. It supplies no rank-four example.

Potential next construction: nontrivial pushout or gluing of asymmetric rank-three barriers, followed by explicit R_3 exclusion using the antitone-fiber recursion. No claim that such a pushout increases rank.

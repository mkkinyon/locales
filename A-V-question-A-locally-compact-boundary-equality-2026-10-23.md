# Locally compact closed boundary theorem for Question A
23 October 2026

Let X be Hausdorff. Assume a closed locally compact Hausdorff subspace Z with open complement e=X\Z that is a union of pairwise disjoint CLOPEN subspaces Y_i of X. Assume every canonical bar on each Y_i has finite separation-tree rank (the bound can depend on i).

THEOREM. The fitted hull generated by finite-rank bar neighborhoods equals V=fit(I) on X.

PROOF. Fix any rectangular bar w on X and put r=j_fin(w), a frame open satisfying w≤r, j_fin(r)=r. For every finite component set E, the complemented block t_E=join_{i,j in E}Y_i box Y_j supports a finite-rank bar v_E=(w meet t_E) join complement(t_E), by finite trees on each diagonal component, D on mixed components, and trivial leaves elsewhere. Then t_E≤v_E→w≤r. Joining finite E gives e box e≤r.

For each clopen component c=Y_i with complement d, the rank-two strip bars p=(c box 1) join (1 box d) and q=(d box 1) join (1 box c) exclude d box c and c box d, respectively. Since r is fixed by both open nuclei (p→r=q→r=r), Heyting adjunction yields those cross rectangles below r. Since c box c≤e box e≤r, we obtain c box 1≤r and 1 box c≤r. Join all i: (e box 1) join (1 box e)≤r.

Therefore the residual closed sublocale R=C(r) is contained in Z×locZ. Because Z is locally compact Hausdorff, its localic square is spatial (ordinary product). The restriction of R is a CLOSED sublocale of that spatial square, hence spatial.

Take a hypothetical ordinary point (z,z') of R.
If z=z', impossible: the diagonal pullback of the bar identity implies w contains every ordinary diagonal pair, and r≥w.
If z≠z', choose compact CLOSED neighborhoods A,B of z,z' IN Z with disjoint interiors and A∩B=empty (possible by local compact Hausdorff regularity of Z). As compact disjoint sets in Hausdorff X, A,B admit disjoint ambient open neighborhoods U,V. Define rank-two dual-far strip
  s=((X\A) box 1) join (1 box (X\B)).
Its bar certificate: first split 1=(X\A)∨U; below U split second 1=(X\B)∨V, with U∧V=0, giving a D leaf. Its restriction to Z×Z vanishes on A×B, which includes a relative open neighborhood of (z,z'). Since s→r=r, the open O(s) must meet R DENSELY. But R has a nonempty relative open part in int_Z(A)×int_Z(B) on which s vanishes, contradicting density. Thus R has no ordinary points. Since R is spatial, R=0, hence r=1.

Because w was an arbitrary bar, j_fin(w)=1 for all bars, so j_fin=j_V and V_fin=V.

This strictly generalizes the one-point fan theorem and the pure clopen disjoint-union theorem. In particular, even a complicated locally compact compact/Cantor/convergent-sequence boundary on which arbitrarily high finite-rank clopen pieces accumulate cannot cause finite-rank fitted-hull failure.

The result does not require any uniform finite bound across Y_i and says nothing about actual rank of global bars: high or transfinite tree ranks can occur. Global Question A without local compactness or such clopen localization remains OPEN.

Proof caveat: density equivalence uses v→r=r iff C(r)∩O(v) is dense in C(r); this is the same established locale identity used for the rational graph strip counterexample. The argument uses spatiality only for the closed locally compact boundary product, never for the ambient localic square.
